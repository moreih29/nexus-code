# NexusCode — 한국어 용어집

앱 문구(`src/shared/i18n/locales/{en,ko}`)를 쓰거나 고칠 때 따르는 단어와 규칙입니다. `tests/unit/shared/i18n-glossary.test.ts`가 지킵니다.

## 용어

| 영어 | 한국어 | 쓰지 않는 말 |
|---|---|---|
| conversation, chat, (에이전트) session | 대화 | 채팅, 세션 |
| fork | 포크 | 분기 |
| file | 파일 | |
| task | 작업 | 태스크 |
| workspace | 워크스페이스 | 작업 공간 |
| resume | 이어하기 (한 단어) | 재개, 이어 하기 |
| agent view | 에이전트 보기 | 에이전트 뷰 |
| instructions | 지시 | 지시사항 |
| editor | 편집기 | 에디터 |
| reload, refresh | 새로 고침 | 새로고침 |
| full access (Codex) | 전체 권한 | 전체 접근 |

"세션"은 SSH·터미널 연결, 사용량 한도의 세션 창, 앱을 한 번 실행하는 동안처럼 대화가 아닌 것에만 씁니다.

## 상태

| 무엇 | 한국어 |
|---|---|
| 대화가 일하는 중 | 작업 중 |
| 대화가 끝나고 아직 안 본 결과 | 새 결과 |
| 서브에이전트·실행이 도는 중 | 실행 중 |
| 서브에이전트·실행이 끝남 | 완료 |

## 에이전트 설정값

설정 › 프로필, 탭의 /config 창, 입력창 모드 메뉴가 같은 키(`common:agentConfig.*`)를 읽습니다.

| 설정 | 값 | 한국어 |
|---|---|---|
| Claude 권한 모드 | `default` | 수동 |
| Codex approval | `on-request` · `never` · `untrusted` | 필요할 때 묻기 · 묻지 않기 · 신뢰하지 않는 명령만 묻기 |
| Codex sandbox | `read-only` · `workspace-write` · `danger-full-access` | 읽기 전용 · 워크스페이스만 쓰기 · 전체 권한 |
| Codex web search | `disabled` | 끄기 |

## 문장 규칙

- 앱 안 문구는 짧은 명사구, 문어체로 씁니다. 설정 화면은 마침표 없는 짧은 조각을 " · "로 잇습니다.
- 요청하는 문장은 "~하세요."로 씁니다. "~하십시오."는 쓰지 않습니다.
- 오류 토스트는 완전한 문장으로 씁니다("~할 수 없습니다.").
- 보간값(`{{name}}`) 바로 뒤에 받침에 따라 바뀌는 조사(을/를, 이/가, 은/는, 과/와, 으로/로)를 두지 않습니다. "{{file}} 파일을", "{{port}}번 포트를"처럼 명사를 하나 넣거나 "에"처럼 바뀌지 않는 조사를 씁니다.
- 같은 영어 문구는 같은 한국어로 옮깁니다. 뜻이 달라 갈라야 하면 테스트의 예외 목록에 이유와 함께 적습니다.
- 메뉴의 명령 이름은 설정 › 단축키의 이름(`settings:keybindings.command.*`)을 그대로 씁니다. "…"이 붙는 메뉴 항목만 `menu:*`에 따로 둡니다.
